# Fabric Modpack Foundation

## Target

Minecraft 1.20.1 with Fabric Loader and Java 21.

## Required Gameplay Mods

| Mod | Purpose | Notes |
|---|---|---|
| Fabric API | Core Fabric dependency | Required by most Fabric mods. |
| Create | Transport, industry and mechanical gameplay | Confirm exact 1.20.1 compatible build. |
| Steam 'n' Rails | Create train expansion | Requires Create. |
| Chipped | Building block variety | Confirm client/server requirements. |
| Handcrafted | Furniture and immersive interiors | Confirm 1.20.1 dependency set. |
| FTB Chunks or equivalent | Claims and map/territory control | Evaluate compatibility and permission model. |

## Performance Mods To Evaluate
